# Examples: USM Harvard (Harvard-USM Ver 2020)

Examples follow the lecture slides "Referencing" (Assoc. Prof. Dr WM Zahiruddin, MPH GKT517 USM 2023/2024) and the Harvard-USM Ver 2020 style. Fictitious details are marked. Check each against the original source before use.

## In-text citations

| Situation | Output |
|---|---|
| 1 author, outside sentence | (Smith, 2013) |
| 1 author, inside sentence | Smith (2013) described that... |
| 2 authors, outside sentence | (Zahiruddin & Naing, 2002) |
| 2 authors, inside sentence | Zahiruddin and Naing (2002) described that... |
| 3+ authors | (Wilson et al., 1997) or Wilson et al. (1997) |
| Same author, same year | (Johnson, 1994a); (Johnson, 1994b) |
| Several sources | (Smith, 1999; Jones et al., 2001; Turner & William, 2006) |
| Organisation as author | (WHO, 2013) |
| No author, title used | ("New Child Vaccine," 2001) |
| Secondary source | (Miller, 1953, as cited in Agrios, 2005) |
| Personal communication | (J. D. Black, personal communication, May 30, 2013) |

## Common mistakes to flag

- Writing "Anonymous" instead of the organisation or title.
- Using `and` in brackets: write `&` in brackets, `and` in the sentence.
- Writing `et al.` in the reference list: list all authors up to 20.
- Missing a, b, c for same author, same year.
- Using `(Ed.)` for two editors: use `(Eds.)`.
- Not italicising journal names in Word.
- Italicising the volume (APA style). In Harvard-USM the volume and issue are **bold**, for example **36(1)**.

## Examples from a USM MPH report (EndNote Harvard-USM output, corrected)

These come from the reference list of a USM MPH research report (GKT517, 2024) that used the Harvard-USM EndNote style. Each shows the original EndNote output and the version this skill returns.

**Article number in place of pages**
Original: `... Sustainability, 14(18), 11543. doi: https://doi.org/10.3390/su141811543`

**Volume only, with article number**
Skill: `Čábelková, I., Gardanova, Z., Neimatov, E. & Esaulov, V. (2021). Spatial accessibility assessment to healthcare facilities: Urban and rural areas. E3S Web of Conferences, 301, 02004. https://doi.org/10.1051/e3sconf/202130102004`

**Other problems to flag when checking a real list**
- Two references joined in one paragraph (for example a DOI followed directly by the next author's name). This often happens when references are copied from a PDF.
- Spaces inside a DOI or URL, such as `s40520-021- 01817-y`. Remove them. These usually come from line breaks when text is copied from a PDF.
- A full stop after the DOI.
- An author name that looks wrongly split, such as `DP, N.`. Mark it `[CHECK: author name]`.
